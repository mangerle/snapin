功能一览

从截取、标注到贴图、识别,一条龙完成

截

截图

  • 区域框选、8 锚点缩放、历史选区回溯
  • Linux 零白闪原生截图,自动降级 Portal;Windows / macOS 通过 xcap 截屏
  • 像素放大镜与 HEX / RGB / HSL 取色
  • 窗口吸附、整屏截图、延时截图(Linux 需 GNOME 扩展)
注

标注

  • 矩形、椭圆、箭头、画笔、荧光笔
  • 文字、序号、马赛克、局部模糊、聚光灯
  • 撤销 / 重做,复制、保存、贴图
贴

贴图

  • 剪贴板图像、文本、颜色一键置顶
  • 滚轮缩放、旋转、翻转、透明度
  • Linux Wayland 真透明 ARGB8888 呈现,其他平台回退 softbuffer
  • 多窗口工作区与分组管理
文

OCR 与翻译

  • 内置 PP-OCRv6 模型,离线识别不上传图像
  • 谷歌、必应、百度、有道、阿里云
  • 图上原位翻译,多种背景覆盖模式
集

系统集成

  • [Linux] 配套 GNOME Shell 扩展
  • 5 个可自定义全局快捷键
  • [Linux] systemd 用户服务,开机自启;Windows / macOS 托盘常驻
  • 设置中心保存后热重载守护进程配置
Rs

纯 Rust

  • winit + tiny-skia 软件光栅化,Linux / Windows / macOS 同源代码
  • 轻量稳定,三大平台同源代码
  • Apache-2.0 开源

快速开始

三步即可使用,全程图形界面

1

下载安装

  • 按平台下载对应安装包
  • 双击安装,或解压便携版
2

初次设置

  • Linux 需注销并重新登录一次
  • 以加载 GNOME 配套扩展
3

开始使用

  • 从托盘打开设置中心
  • 自定义快捷键后即可截图、贴图

Linux 完整功能需 Wayland 会话(推荐 GNOME 45-51),X11 未做适配不保证可用。Windows 10+,macOS 需授权屏幕录制。
